| Код | Требования                         | Комментарий  |
|-----|------------------------------------|--------------|
| F   | Функциональные (Functionality)     |              |
|     | Необходимо обеспечить работу сайта и интернет-банка                                |              |
|     | На сайте клиент должен видеть список доступных депозитов с актуальными ставками                                |              |
|     | На сайте подать заявку на депозит можно с помощью ФИО и номера телефона                                 |              |
|     | Данные от публичных частей систем (сайт и приложение) должны передаваться с помощью шифрования трафика                                |              |
|     | В интернет банке ставки для депозитов должны расчитываться индивидуально под каждого клиента с актуальной информацией и отображаться клиенту                                 |              |
|     | Подача заявок на депозит должна осуществляться как через сайт, так и через интернет-банк                                |              |
|     | Заявки на открытие депозита в MVP обрабатываются менеджером банка вручную                               |              |
|     | Должна поддерживаться автоматизация процесса согласования ставок с бэк-офисом через Excel                                |              |
|     | Все важные операции от клиентов должны подтверждаться с помощью СМС-кода                               |              |
|     | Расчет ставок по депозитам лучше перенести в АБС-систему, отказавшись в итоге от XLS-файлов и ручных расчётов                               |              |
| U   | Удобство использования (Usability) |              |
|     | Быстрый отклик интерфейса в системах банка < 1 секунды                                |              |
|     | Один единый UI дизайн темы для интерфейсов банка с учетом бренда                               |              |
|     | UI должен быть интуитивно понятный                                |              |
|     | Если того предполагают бизнес-процессы, должны доставляться СМС и другие нотификацию пользователю для информирования                                |              |
| R   | Надёжность (Reliability)           |              |
|     | Система должна иметь возможностью горизонтального масштабирования при высоких нагрузках      |              |
|     | Сбой в микросервисах/приложениях не должен влиять на остальную инфраструктуру банка                              |              |
|     | Все сервисы должны работать 24/7 и быть доступны в 99,9% случаев                              |              |
|     | Необходим резервный ЦОД                              |              |
| P   | Производительность (Performance)   |              |
|     | Актуальные ставки должны рассчитываться менее чем за 1 секунду                                |              |
|     | Системы на запросы должны отвечать менее, чем за 1 секунду                                |              |
| S   | Поддерживаемость (Supportability)  |              |
|     | Все решения по работе системы должны быть задокументированы                                |              |
|     | Должны быть описаны регламенты по работе с критическо-важными сценариями или точкам системы                                |              |
|     | Изменение в работе сервиса не должны оказывать влияние на существующие МС по возможности                               |              |
|     | Должно обеспечиваться максимальное применение текущих технологий и компетенций внутри банка                              |              |
| +R  | + Ограничения (Restricitions)      |              |
|     | Использование MS SQL, PostgreSQL (как аналог), Oracle, Java, React, PHP, ASP.NET MVC 4.5 на основе .NET Framework 4.5 или новые технологии, совместимые с текущими                                |              |
|     | Учитывать возможность использования Kafka как брокера очередей                                |              |
|     | Все обмены данными (REST API, excel) должны быть зашифрованы и использовать защищённые протоколы передачи данных                               |              |
|     | Конфеденциальные данные должны шифроваться                             |              |
|     | Аутентификация возможна по СМС                             |              |
|     | Для отправки СМС сообщений должен использоваться текущий телеком-шлюз с доработками от ИТ-специалистов банка                             |              |
|     | Необходимо предусмотреть равномерное распределение запросов по инстансам сервисов (балансировка)                             |              |
|     | Нужно учитывать, что АБС может масштабироваться только вертикально из-за своей базы данных                             |              |
|     | Лучше избежать прямой работы интернет-банка с API АБС в новом процессе, поэтому необходимо будет часть нужных функциональностей вынести из АБС в новые сервисы                             |              |
