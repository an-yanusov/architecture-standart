### <a name="_qmphm5d6rvi3"></a>**Решение**
Для расчета актуальный ставок будет разработа отдельная система по управлению депозитами:
- получение актуальных ставок и кэширование + генерация файла XLS для консультаций
В будущем система может развиться до замены АБС-модуля Депозитов.

Все обращения к файлам будут идти через новую систему и она будет высоконагружена, так как s3 не ест много ресурсов (обеспечим очистку старых файлов), а редис может отдавать сразу актуальный URL на файл.

В контуре банка предполагается, что есть некий балансер/api-gateway, который будет защищать от угроз внешнего трафика и проксирование к МС будет идти через него. Поэтому обращение из системы партнёра будет идти не напрямую в МС/S3, а через внешний API_GATEWAY.


### <a name="_bjrr7veeh80c"></a>**Альтернативы**
1) Разработать МС в контуре CRM системы
2) Актуальное изменение о ставках АБС будет пушить в очередь Kafka, а Сервис депозитов получать из неё данные для своей функциональности. 


**Недостатки, ограничения, риски**
Необходимо будет убедиться, что сотрудники кол-центра получают актуальную информацию и согласовать с бизнесом лаг по ставкам (например, 15 минут).
